# ADR-004: HyperFrames Component Architecture & Registry

**Status:** ACCEPTED  
**Date:** 2026-08-31  
**Deciders:** Head of Engineering, Frontend & Render Systems Team  
**Scope:** HyperFrames Integration (`adapters/hyperframes/`, `src/hyperframes/`)  

---

## 1. Context & Problem Statement

Generating programmatic video animations directly by generating raw, unconstrained HTML, CSS, and JavaScript with large language models causes severe production failure modes:
1. **Broken Layouts & Overflows**: Unpredictable CSS positioning breaking outside screen safe zones.
2. **Infinite Loops**: Unbounded animation loops (`repeat: -1`) causing headless renderers to hang indefinitely.
3. **Remote Dependency Failures**: External image or script URLs failing to load during offline rendering.
4. **Code Duplication**: Re-inventing visual cards, charts, and split screens on every generation.

---

## 2. Decision & Architecture

We decided to build the **H9 HyperFrames Component Registry** (`src/hyperframes/components/`) and an isolated adapter interface (`adapters/hyperframes/`).

### 2.1 The 7 Reusable Parameterized Blocks
Instead of writing raw HTML/CSS from scratch, scripts select from 7 verified visual building blocks:
1. `ReferenceCollageHook`: 3-card dynamic visual stack with staggered entrance.
2. `SplitScreenIntro`: 50/50 comparison layout with animated center divider.
3. `QuoteHighlight`: Prominent citation callout with quotation glyph and author badge.
4. `TimelineReveal`: Vertical/horizontal milestone progression with glowing nodes.
5. `StatisticReveal`: Large-format kinetic number counter with contextual radial glow.
6. `ComparisonPanel`: Side-by-side feature matrix with checkmark transition badges.
7. `CreatorBottomCollage`: Persistent branded lower-third creator card.

### 2.2 Master GSAP Timeline Protocol
All component animations compile into deterministic GSAP timeline code bound to `window.__timelines["root"]`. The headless renderer advances time deterministically via `.seek(t)`.

### 2.3 AST & Composition Linter
Every generated composition must pass strict automated linting before rendering:
- Verifies `<div data-composition-id="root">`.
- Rejects any remote `http://` or `https://` assets (enforces local asset freezing).
- Prohibits infinite animation loops.
- Enforces safe-zone margin constraints ($64\text{px}$ horizontal, $120\text{px}$ vertical).

---

## 3. Consequences & Trade-Offs

### Positive Consequences
- **100% Render Reliability**: Parameterized blocks prevent broken HTML layouts and infinite render loops.
- **Aesthetic Consistency**: Standardized typography, easing curves (`power2.out`), and spacing.
- **Offline Hermetic Rendering**: All assets are guaranteed to be local, enabling 100% offline rendering.

### Negative Consequences / Mitigations
- **Fixed Component Set**: Visual variety is initially bounded to registered blocks.
  - *Mitigation*: The component architecture is modular; new blocks can be added by implementing `BaseComponent`.
