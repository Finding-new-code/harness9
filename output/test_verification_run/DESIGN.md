# DESIGN: The History of the Transistor

## Brand
- Name: TechChronicles
- Tone: Authoritative, Cinematic, Modern

## Colors
- Background: #0a0e17
- Primary Accent: #00d2ff
- Secondary Text: #8fa3bf
- Base Text: #ffffff
- Warning/Alert: #ff5252

## Typography
- Display: 'Inter Tight', sans-serif (700)
- Body: 'Inter', sans-serif (400)

## Motion
- Mood: Cinematic & Fluid
- Standard Easing: power2.out

## What NOT to Do
- Never use unbranded neon greens.
- Never use pure black #000000 background.
- Never hardcode exit fades on intermediate scenes.
